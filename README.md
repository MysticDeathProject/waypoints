# waypoints-navigation for sypb and ebot and yapb and csbot
Due to the fact that HsK_CNN has abandoned the updates of sypb, it was decided to just create a separate topic with ewp and pwf and formats of waypoints for different bots, be it sypb or ebot or yapb bots, but it's better to download the whole archive.

## Goals of the project
<ul>
<li>Fix waypoints for real time</li>
<li>CPU performance optimization</li>
<li>Small helping for any projects</li>
  <li>Make the best waypoints for zombie mod ONLY</li>
    <li>This will add .nav files to support navigation for official bots. I did this for my own convenience, so I don't get lost in the list of maps that still need tweaking for the best possible experience in Zombie Mode</li>
</ul>

## Zombie Escape Waypoints 2026
<ul>
<li>Bots in Zombie Escape don't always manage to escape successfully by helicopter. Use the commands (ebot_quota 1, sys_ticrate 1000) or (ebot_quota 5, ebot_ignore_enemies 1, sys_ticrate 1000). If the bots have attack mode enabled (ebot_ignore_enemies 0), they are less likely to fulfill the main objective on the Zombie Escape map, which is to escape via helicopter, so the errors are not only related to my waypoints but also to EfeDursun125’s code itself. Therefore, wait for a full update from EfeDursun125, and for now, it’s better to use ebot v1.07 R12 or older versions when using my waypoints for Zombie Escape maps. The probability that bots will get into the helicopter is sypb is 0.5%, while with ebot v1.07 R12, the chance of bots being rescued by the helicopter is 7%. Don’t forget that waypoints are good, but updating the bots themselves using C++ is far more important.</li>
</ul>
